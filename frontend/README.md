# Konditer Plan Frontend

Фронтенд приложение для управления кондитерским производством на React + TypeScript.

## Структура приложения

Приложение состоит из 4 основных вкладок:

### 1. Заказы (Orders)
- Просмотр списка заказов
- Создание новых заказов
- Редактирование и удаление заказов
- Поля: рецепт, количество, дата доставки, статус

### 2. Расписание (Schedule)
- Просмотр расписания кондитеров и оборудования
- Запуск планирования производства
- Грид с временными слотами (9:00-18:00)
- Отображение назначений на каждый час

### 3. Склад (Inventory)
- Просмотр ингредиентов и их остатков
- Подсветка ингредиентов с низкими остатками
- Управление инвентарем (текущее количество, минимум, дата проверки)

### 4. Рецептуры (Recipes)
- Просмотр списка рецептов
- Детальная информация по каждому рецепту:
  - Операции производства (последовательность, длительность, оборудование, квалификация)
  - Ингредиенты (количество на единицу продукции)

## Технологии

- **React 18** - основной фреймворк
- **TypeScript** - типизация
- **React Router** - навигация
- **Fetch API** - HTTP запросы к бэкенду

## Установка и запуск

1. Установите Node.js (версия 16+)
2. Перейдите в папку frontend:
   ```bash
   cd frontend
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите приложение:
   ```bash
   npm start
   ```
5. Откройте http://localhost:3000 в браузере

## API

Приложение взаимодействует с FastAPI бэкендом на порту 8000.
Убедитесь, что бэкенд запущен перед использованием фронтенда.

## CRUD операции

Все 11 сущностей поддерживают полные CRUD операции:
- Orders (Заказы)
- Schedule (Расписание)
- Ingredients (Ингредиенты)
- Inventory (Инвентарь)
- Recipes (Рецепты)
- RecipeOperations (Операции рецептов)
- RecipeIngredients (Ингредиенты рецептов)
- Confectioners (Кондитеры)
- Qualifications (Квалификации)
- EquipmentTypes (Типы оборудования)
- Equipment (Оборудование)
